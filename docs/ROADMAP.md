# Roadmap

## Foundation 0.1

- [x] Light-pink mobile visual system
- [x] Five-day beginner program under one hour per session
- [x] Guided strength, rowing, and treadmill exercises
- [x] Set completion and workout history
- [x] Optional private weight and waist check-ins
- [x] Installable offline foundation

- [ ] Backup export and import

## Later

- [ ] Flexible calendar and missed-workout recovery
- [ ] Conservative, approval-based progression recommendations
- [ ] Optional reminder support
- [ ] Phase milestones based on comfort, adherence, and movement quality
